# Liz Word Lab：收费应用上线前评估与首轮实现

核查日期：2026-11-16（北京时间）。状态：功能预览，不是可提交商店的正式应用。

## 产品定位

面向已经在其他工具背过英文单词、希望验证掌握程度的考试学习者。核心价值是把本人截图中的目标单词转成可靠的测试和复习任务。首发不承诺提分、不冒充官方考试产品、不把识词变成自由生成单词。

新增 `/next/` 入口；原版及原学习数据保留。新版使用独立数据键，不自动迁移旧数据。代码拆成识词/测验领域逻辑、文案、UI、样式和测试文件。

## 国际化配置与验收

三个独立配置：`uiLocale`（界面）、`glossLocale`（辅助释义）、`targetLanguage=en`（所学英语）。本轮仅实现界面语言选择与英文释义，尚未实现母语释义切换。

| 批次 | 范围 | 决策理由与状态 |
|---|---|---|
| 首轮配置 | English、简体中文、繁體中文、Español、Português (Brasil)、Français、Deutsch、日本語、한국어、Tiếng Việt、Bahasa Indonesia、Türkçe | 参考 Quizlet 覆盖的欧洲、东亚和东南亚语言，兼顾当前用户验证与国际扩展；已加入12种主要界面文案，翻译均属待母语验收草稿 |
| 首轮内容 | 英文释义、英语语音、英文目标单词 | 用英文释义进行练习，独立于界面；未提供的语言绝不以中文内容假冒本地化 |
| 下批候选 | 阿拉伯语、俄语、印地语 | 需结合真实试用需求、留存、客服能力排序；阿拉伯语另需RTL布局，不能只翻译文字 |
| 多语释义 | 首先中英，再按试用需求扩展 | 先获得可靠且允许商用的词典/翻译供应，再做义项及答案一致性验证 |

系统语言自动匹配；用户可覆盖并保存在本机；不支持的语种回退英文。葡萄牙语本轮统一巴西葡语，未提供葡萄牙地区的独立翻译。当前非简中语种的服务提示、隐私说明和部分错误消息回退英文，并在设置中明确说明，不能将12种主界面草稿宣传为12种完整上线语言。

上线前每种语言必须通过：关键路径、隐私和购买文案完整翻译；母语审读；窄屏/大字号；长文案；无截断；地区格式；声音可用与降级；对应商店截图和客服入口。没有通过的语言不列入正式商店支持语言。

## 已实现

- 新版独立入口，响应式移动端布局、显式按钮标签和键盘焦点。
- PNG/JPEG/WebP，最多5张、每张10MB；本机OCR、逐词选择和编辑；原图可打开对照。
- 单词严格校验：每行一个单词，保留词内连字符与撇号；拒绝整句、短语和释义行，避免 bind 变成 bind trees。重复词去重。
- OCR 低置信度、单字母和常见界面词默认不选中；置信度是OCR引擎分数，不是识词正确率保证。
- 保守处理每一视觉行的首词；多列/英文释义并排需要用户上传前先裁剪成单列。没有声称已解决任意版式。
- 无行结构时回退文本，但所有候选词默认不勾选。绝不静默补词、改成近义词或拼成短语。
- OCR可取消，加载失败可粘贴词表；失败时保留既有候选。
- 第三方词典调用前单独说明数据流并取得勾选；截图不传词典，只传确认词汇。
- 字典请求超时、并发限制；成功词保留，失败词可重试，不因一个生词失败阻塞整批。
- 词义选择、拼写测试；答案去重；词义不足时不编造题，提示可听写；按当前词条义项练习，不声称近义词有唯一正确性。
- 错词十分钟后重现，答对后按1/3/7/14/30/60天间隔；这是透明的简化复习规则，不声称已采用FSRS。
- 每次作答保存，可暂停继续；导出/恢复JSON；恢复前格式校验与替换确认；仅删除新版数据。
- 未启用收费、广告或统计；现有版50词和原有题型未被移除。

## 不能作为正式上线能力的部分

1. OCR：仍是浏览器Tesseract，英文标签可能仍被识成词，词表必须人工确认。多列自动拆分、图片内裁剪及原图定位高亮未实现。
2. 内容：词典首个可用义项不等于考试最常考义项；本轮已追加多义项选择，未确认义项不开放词义测试。未完成商用词典逐条授权审计、多语释义、语境题唯一性审查与可商用例句库。新版只开放词义/拼写，不复用未经质量验收的生成语境题。
3. 离线：已存词表及成绩不需要再次请求词典，但页面和OCR初次资源需要网络；没有服务工作线程或完整离线承诺。
4. 网络：外部CDN和Free Dictionary API在中国大陆的连通性、限流和可用性未验收；不能收费依赖无SLA的免费端点。首版移除了未正式接入的在线机器翻译调用。
5. 数据：本机浏览器存储，非云同步；没有账户、服务器备份与旧版迁移。隐私告知是测试版事实说明，缺少发布主体信息，不能直接冒充最终法律文本。
6. 国际化：主文案12语种草稿，完整语言验收仍待完成。
7. 原生：没有签名IPA/AAB、商店购买、恢复购买、订单验证、原生相册/分享导入、原生OCR或真机测试。

## 正式产品的实现方向

沿用当前纯领域模块，UI迁移为可打包客户端；原生桥接应提供相册选择/分享导入、系统OCR、离线词典和本机语音。iOS端可评估Vision，Android端可评估ML Kit；最终SDK版本、系统下限、许可需在实现时查官方资料。

OCR管道：选图→本机裁剪→识别文字与坐标→版面分区→候选词（原文、坐标、置信度、图片来源）→逐词确认→查词→测试。禁止让生成模型扩大确认词表；不自动改写词形。单词/短语应是未来显式分开的导入模式，本版仅单词。

词条数据需要：原拼写、规范查词形式、词性、义项ID、英文释义、辅助语言译文、审校状态、发音源、例句来源、许可与版本。多义词先选义项再出题；相近且均可成立的选项不能互作单选干扰项。无法审定的词条只开放可核对的题型。

正式复习需记录题型、义项、错误类型、实际复习时间，并区分拼写错/词义错。先保持简单可解释，积累真实数据后再考虑校准模型，不宣称一轮测试证明长期掌握。

## 收费模式建议（尚未配置价格或交易）

- 免费体验：完整体验截图→确认→测试，允许导出自己的学习数据。
- Pro买断：本机识词、无限自建词表、离线练习和高级统计；前提是成本主要在端侧且无持续付费API。
- 可选订阅：确实有持续成本的云同步、授权内容和云端增值功能；不把基础本机功能伪装成有持续服务成本。
- 具体免费额度和价格先用OCR成本、词典授权费、退款与试用留存验证，再决定；当前未承诺“终身无限AI”。

## 质量门槛（目标，尚未达成）

- 建立有权使用的至少200张真实截图金标准：常见背词应用、字号、深浅色、裁剪、双列、英文释义、低清图、复习提示、专有名词、连字符、屈折形式。
- 选定支持版式范围内，自动选中的候选词精确率目标≥99%，召回率目标≥95%；逐样本报告，不把确认后准确率冒充自动OCR准确率。
- 确认词表外新增词为0；未审核候选不自动入库；未确认词不混入本批测试。
- 词义选择题全部有来源且答案可审定；多义与近义争议题移除。
- 测试1000次作答、异常退出和升级恢复，没有已保存记录丢失或重复记分。
- 每种首发语言在320/390/768/1280宽及系统大字下走通核心流程；关键文案无英文/中文混杂（英文学习内容除外）。
- OCR速度/内存/首载体积先在目标真机测量再定SLO，不提前宣称秒识别。

## 本轮验证

运行 `node --test next/tests/core.test.cjs`：11项通过，覆盖只接受单词、bind不拼接trees、UI标签默认不选、低置信度校对、文本回退、块结构、去重、题目答案一致性、拼写判分、复习时间、12语种主文案完整性。

这些是代码层逻辑测试，不是OCR实图准确率测试、端到端浏览器测试或商店验收。本地预览跨环境连接被拒绝；部署后已确认公开入口可访问，实测拒绝bind trees，真实导入bind/benefit/abandon/reliable，发现首义项风险后追加义项选择。浏览器完整测试结果见后续补充。
